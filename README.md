# helpdesk-http-lab – матеріали до практичної роботи № 3

Освітній компонент «Розробка клієнт-серверних застосувань», розділ 2.
Тема: аналіз HTTP-взаємодії засобами інструментів розробника браузера та Postman.

Лабораторний сервер служби технічної підтримки коледжу. Сторонніх залежностей немає –
лише вбудовані модулі Node.js, тому `npm install` виконувати не потрібно.

## Запуск

```
npm start
```

| Адреса | Що це |
|---|---|
| http://localhost:3000 | сторінка служби підтримки (клієнт) і API `/api/...` |
| http://localhost:5500 | «сторонній» сайт – інше джерело для перевірки CORS |

Налаштування – у файлі `.env` (створіть його копіюванням `.env.example`). Після зміни `.env` перезапустіть сервер (Ctrl+C, `npm start`).
Дані зберігаються в пам’яті: після перезапуску сервера повертається початковий стан.
У терміналі сервер виводить журнал запитів: метод, шлях, код стану, час, джерело (Origin).

## Маршрути API

| Метод і шлях | Призначення |
|---|---|
| GET /api/health | стан сервера |
| POST /api/auth/login | вхід, повертає токен Bearer |
| GET /api/tickets?status=&priority=&page=&pageSize= | список заявок (JSON або CSV – за заголовком Accept) |
| POST /api/tickets | створити заявку (потрібен токен) |
| GET /api/tickets/{id} | одна заявка (підтримує If-None-Match) |
| PATCH /api/tickets/{id} | часткове оновлення (потрібен токен) |
| DELETE /api/tickets/{id} | видалення (лише адміністратор) |
| POST /api/tickets/{id}/status | зміна стану заявки |
| GET /api/old-tickets | стара адреса – переспрямування 301 |
| GET /api/slow?ms=1500 | повільна відповідь |
| GET /api/error | імітація помилки сервера |
| GET /api/limited | обмеження частоти: 5 запитів за 10 с |

Помилки повертаються у форматі `application/problem+json` (RFC 9457).
